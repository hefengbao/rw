# 【番剧】画完这个再去死

## 片头曲

比如说
散步途中看见的花
莫名感到寂寞的黄昏时分
展现出无数样貌的蓝色
以及那些不该说出口的话
我想把这个渺小人类的生活
把那些让我再也移不开目光的东西
全都狠狠摔在这里
直到毫不保留的写尽为止
我想用这种方式好好的拯救此刻的自己
在某个陌生的地方
在某个陌生的未来
刺进陌生的你心里
从此再也拔不出来...
那种事根本怎样都无所谓
连睡觉这件事
连吃饭这件事
连望向大海这件事
还有消耗这段人生的一切
全都用来画着这个
活下去
我就在这里


## 片尾曲

用像踏出第一步那样的步伐
打算去看海滨绽放的花
如你所言我是个胆小鬼
放不下痛楚
时钟的指针刻画着岁月持续向前
缝合那段勉强撑过的时光持续向前
在灵魂深处浮现的形状
在悲伤深处浮现的朝阳
想试着去理解某人与他们
好像理解看看啊

时钟的指针刺向心头又持续向前
即使不说出曾经如此描绘的梦想
也想试着去理解自己与我
好像理解看看啊
